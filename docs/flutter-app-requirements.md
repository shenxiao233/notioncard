## 2. 背景与目标

### 2.1 背景

现有 Electron 应用已经形成较完整的知识库、卡片库、FSRS 复习、牌组市场、账户和云同步能力。Flutter App 的目标不是重新定义业务规则，而是将这些能力迁移到移动端，提供适合手机操作的离线优先体验。

现有 Electron 实现中的数据来源包括本地结构化数据和云端 V2 API。核心本地对象包括文档、卡片、复习事件和设置；云端同步对象包括 `CARD`、`DOCUMENT`、`SETTINGS`，后端还存在 `DECK` 及设备同步模型。

### 2.2 产品目标

1. 用户可以在手机上登录账户，浏览自己的知识库和卡片库。
2. 用户可以在无网络或弱网络环境下阅读已经缓存的文档和卡片。
3. 用户可以按照 FSRS 计划完成每日复习，并查看复习反馈、历史和趋势。
4. 用户可以浏览牌组市场，查看牌组详情，并下载或订阅公开牌组。
5. App 可以可靠地同步内容、复习状态、设置和市场订阅状态。
6. App 的移动端交互应符合系统返回、网络状态、生命周期和权限习惯。

### 2.3 非目标

当前版本不承担 Electron 桌面端的全部能力，不迁移桌面窗口、自动更新、文件选择器和 PDF 导出等桌面特性。

## 3. 范围定义

### 3.1 当前版本必须支持

- 登录、注册、邀请码注册、自动登录、退出登录。
- 首次登录后的昵称、简介和头像资料展示；资料编辑可按产品排期决定是否开放，MVP 建议仅展示并提供退出登录。
- 知识库文件夹、文档列表、搜索、文档详情阅读。
- Markdown、GFM、LaTeX、代码块、图片、链接和目录内容的移动端渲染。
- 卡片库浏览、搜索、筛选、排序、分页或加载更多。
- 单选题、多选题、判断题和速记词条的只读详情。
- 到期复习、独立复习、答题反馈、FSRS 评分和复习完成页。
- 今日复习历史、复习统计、连续学习天数和热力图。
- 牌组市场搜索、排序、分页、详情、收藏、下载或订阅。
- 已下载牌组的本地导入和版本信息保存。
- 本地缓存、离线访问、同步状态、重试和账户隔离。

### 3.2 当前版本明确不支持

以下能力在 App 端必须隐藏入口或明确显示“暂不支持”，不可通过误触进入半成品页面：

- 创建、编辑、删除、复制、移动和重排文档。
- 富文本编辑器、Markdown 编辑器、HTML 粘贴、图片插入和 LaTeX 编辑。
- 创建、编辑、删除和批量修改卡片。
- 从本地文件导入卡片，向本地文件导出卡片或全部数据。
- 牌组上传、发布、下架和版本提交。
- 协作卡片贡献、贡献审核和管理员工作区。
- WebDAV 或坚果云备份配置及双向恢复。
- Electron 窗口控制、GitHub Releases 自动更新和桌面 PDF 导出。

复习评分不是内容编辑。用户完成复习后，App 必须写入复习事件和 FSRS 状态，这是当前版本允许的业务写操作。

### 3.3 后续编辑能力预留边界

底层领域模型和 Repository 可以为未来编辑保留接口，但第一阶段不得把编辑 API 暴露给页面层。未来编辑应至少单独设计以下能力：

- 文档编辑草稿、自动保存、冲突预览和发布。
- 卡片字段校验、选项和答案编辑、批量操作。
- 本地文件导入导出权限和系统分享。
- 编辑操作的撤销、重做和细粒度同步。

## 4. 用户角色

| 角色 | 权限和目标 |
| --- | --- |
| 普通学习者 | 登录、阅读、浏览卡片、复习、查看统计、收藏和下载牌组 |
| 牌组订阅者 | 使用已下载牌组，并接收公开版本更新 |
| 牌组作者 | 当前 App 仅展示其公开信息；上传和发布仍由桌面端或后台处理 |
| 管理员 | 当前 App 不提供管理员工作区 |
| 未登录用户 | 默认只能看到登录/注册流程，不进入完整内容和市场数据页面 |

## 5. 产品原则

1. **阅读优先**：内容在手机上应快速打开，排版优先于复杂装饰。
2. **离线优先**：已经缓存的内容和复习队列在断网时仍可使用。
3. **同步可解释**：用户能看到最后同步时间、当前状态和失败原因。
4. **复习不中断**：复习流程中不因普通网络失败阻塞答题和评分。
5. **只读边界清晰**：当前阶段所有内容字段均只读，只有复习结果和用户设置可写。
6. **账户隔离**：不同账户的本地数据、令牌、同步队列和缓存必须隔离。

## 6. 信息架构与导航

### 6.1 一级导航

建议使用底部导航或自适应导航栏：

1. **首页/复习**：今日待复习数量、开始复习、最近复习和进度。
2. **知识库**：文档文件夹和阅读入口。
3. **卡片**：卡片库搜索、筛选和只读详情。
4. **市场**：公开牌组、收藏、下载和订阅。
5. **我的**：账户信息、同步、复习设置、关于和退出登录。

## 7. 典型用户流程

### 7.1 首次使用

1. 打开 App，显示登录页。
2. 用户输入服务器地址、账号和密码，或进入注册流程。
3. 注册时输入邀请码；后端校验成功后创建账户。
4. 如果账户状态为 `INCOMPLETE`，进入昵称、简介和头像完善页。
5. 登录成功后拉取账户数据和服务器设置。
6. 首屏显示同步状态；同步完成后展示今日复习和本地内容。

### 7.2 日常复习

1. 用户进入复习首页，查看今日到期、新卡和剩余数量。
2. 点击开始复习，按当前牌组、顺序和优先级生成队列。
3. 选择题或判断题先选择答案；多选题点击提交。
4. App 展示正确/错误状态和解析，再展示评分按钮。
5. 用户选择 `Again`、`Hard`、`Good` 或 `Easy`。
6. App 本地事务写入卡片 FSRS 状态和复习事件，进入下一张。
7. 复习完成后显示统计，并在网络恢复时自动同步。

### 7.3 离线复习

1. App 启动时从本地数据库加载已缓存卡片、文档和复习计划。
2. 网络不可用时，用户仍可阅读缓存内容和完成复习。
3. 复习结果进入本地同步队列，显示“待同步”。
4. 网络恢复后执行增量同步；冲突按同步策略处理。

### 7.4 下载市场牌组

1. 用户进入市场并搜索牌组。
2. 查看牌组作者、描述、卡片数量、版本、下载量和更新时间。
3. 点击下载/订阅，App 下载牌组包并校验 `manifest.json` 和 `cards.json`。
4. 导入本地卡片库，保存远端牌组 ID、版本和订阅信息。
5. 下次打开详情时检查是否有新版本。

## 8. 页面需求

### 8.1 登录与注册

#### 登录页

- 输入服务器地址、用户名和密码。
- 提供“记住账号”或安全自动登录选项；密码必须存储在安全存储中。
- 显示连接中、超时、账号密码错误、账户被停用等状态。
- 登录成功后保存访问令牌和刷新令牌，并进入全量同步。
- 服务器地址可以在未登录状态修改；登录后只读展示。

#### 注册页

- 输入用户名、密码、确认密码和邀请码。
- 前端做基本格式校验，最终以服务端校验为准。
- 明确邀请码用途和失败原因。
- 注册成功后根据账户状态决定进入资料完善或主界面。

#### 账户状态

`INCOMPLETE`、`ACTIVE`、`SUSPENDED`、`BANNED` 必须有可理解的提示。`SUSPENDED` 和 `BANNED` 不得进入云端数据页面。

### 8.2 复习首页

页面内容：

- 今日待复习总数。
- 到期复习、新卡数量。
- 今日已完成数量和每日上限。
- 当前复习牌组/文件夹。
- 开始复习按钮。
- 进入独立复习入口。
- 最近复习历史摘要。
- 连续学习天数、今日复习次数和热力图摘要。
- 最近同步时间和同步状态。

复习队列必须遵循：

- 排除 `suspended` 卡片。
- `dueAt <= 当前时间` 的卡片才进入到期队列。
- 遵守 `dailyLimit` 和 `dailyNewLimit`。
- 支持 `new`、`review`、`mixed` 三种优先级。
- 支持按牌组顺序或随机顺序。
- 复习计划按全部牌组或指定文件夹过滤。

### 8.3 复习学习页

#### 通用显示

- 顶部显示当前进度、牌组名称和退出按钮。
- 显示卡片类型、标签和题干。
- 不显示用户编辑控件。
- 网络状态变化不应打断当前卡片。

#### 单选题

- 显示 A-D 选项。
- 点击一个选项后立即判定或进入确认状态，行为需统一实现。
- 答案提交后，正确答案使用明确的视觉标识，错误选择也应标记。
- 有解析时展示解析，无解析时隐藏解析区域。

#### 多选题

- 允许选择多个选项。
- 未选择任何选项时禁用提交。
- 提交后按完整答案集合判断，不能仅判断是否包含某个正确选项。
- 显示正确答案、用户选择和解析。

#### 判断题

- 映射为两个固定选项：正确、错误。
- 数据层仍可使用 `truefalse` 类型和 `A/B` 选项。

#### 速记词条

- 展示速记内容后提供三档反馈：熟悉、模糊、没印象。
- Electron 中“太简单”会映射到 `Easy`，并可能暂停该卡片；Flutter 必须在产品确认后决定是否保留独立的“太简单”入口。
- 第一阶段建议保留 Electron 的三档学习反馈，并将其映射为 `Good`、`Hard`、`Again`；FSRS 四档评分仅用于题目答题后的标准评分。

#### 答案反馈与下一步

- 答案反馈和 FSRS 评分必须分成两个概念：前者表示答题是否正确，后者表示记忆难度。
- 评分按钮固定为 `Again`、`Hard`、`Good`、`Easy`，显示中文说明和下一次复习时间预览。
- 评分完成后立即保存本地状态，再显示“下一题”。
- 支持重新作答当前卡片，但不能重复写入同一轮复习事件。
- 当前版本不提供“删除错题”“编辑卡片”等内容变更操作。

### 8.4 复习完成页

- 显示本次完成数量、用时、各评分数量和下一次复习概览。
- 提供查看今日历史、返回复习首页和查看卡片库入口。
- 队列为空时明确区分“今日计划完成”和“当前筛选范围没有待复习卡片”。

### 8.5 今日历史与统计

- 按时间倒序展示今日复习事件。
- 每条记录显示题干、牌组、时间和评分标签。
- 卡片已经被删除时，使用复习事件中的题干和牌组快照。
- 支持查看总复习次数、连续学习天数和近 52 周热力图。
- 统计以本地复习事件为基础，云端同步后合并去重。

### 8.6 知识库首页

- 显示文档总数和文件夹列表。
- 显示最近更新文档。
- 支持按标题搜索。
- 支持文件夹进入和返回。
- 文档和文件夹均为只读，不显示新增、重命名、删除和移动按钮。

### 8.7 文档详情阅读页

- 显示标题、所属文件夹、创建时间和更新时间。
- 渲染服务端或本地保存的 HTML/Markdown 内容。
- 支持滚动阅读、目录跳转、图片查看和系统浏览器打开外链。
- 页面内禁止出现可编辑输入框和保存按钮。
- 文档不存在时显示可返回知识库的错误页。

### 8.8 卡片库

- 支持搜索题干、牌组、标签、速记内容、知识点和来源。
- 支持按牌组、标签、类型和熟练度筛选。
- 支持按创建顺序、倒序和复习次数排序。
- 支持分页或滚动加载，避免一次渲染全部卡片。
- 列表项显示类型、题干摘要、牌组、标签、熟练度、复习次数和下次复习时间。
- `suspended` 卡片需要有明确状态。
- 不显示新建、编辑、删除、批量删除、导入和导出按钮。

### 8.9 卡片详情只读页

- 单选、多选、判断题显示题干、所有选项、答案、解析、标签、知识点、来源和统计字段。
- 速记词条显示题目、速记内容、标签和复习状态。
- 显示 FSRS 状态、下次到期时间、复习次数、熟练度和正确率。
- Markdown、LaTeX、代码和图片按照统一渲染规则处理。
- 显示“只读内容”语义，不提供编辑入口。

### 8.10 牌组市场

#### 市场列表

- 支持关键词搜索。
- 支持最近更新、最受欢迎、卡片最多排序。
- 支持分页和下拉刷新。
- 卡片显示标题、作者、分类、标签、卡片数、下载量、版本和更新时间。
- 登录用户可以收藏/取消收藏。
- 未登录时按产品门禁要求进入登录页，不展示需要账户的数据。

#### 牌组详情

- 显示标题、作者、描述、分类、标签、版本、更新时间、卡片数量和下载量。
- 显示下载、订阅、已订阅、检查更新等状态。
- 下载前显示预计大小或校验状态；失败后支持重试。
- 下载成功后导入本地卡片库，并建立远端牌组与本地牌组映射。
- 当前版本不显示上传、发布、下架和协作贡献入口。

### 8.11 我的与设置

- 显示昵称、头像、简介和账户状态。
- 显示本地数据数量和订阅牌组数量。
- 复习设置：目标记忆保持率、每日复习上限、每日新卡上限、复习优先级、顺序模式。
- 同步设置：立即同步、最后同步时间、待同步数量、失败原因和重试。
- 显示服务器地址、设备标识摘要和应用版本。
- 提供修改密码和退出登录；修改密码调用服务端接口。
- 不提供桌面端文件路径、自动更新和 WebDAV 设置。

## 9. 内容渲染规范

### 9.1 Markdown/GFM

至少支持：标题、段落、粗体、斜体、删除线、无序/有序列表、嵌套列表、任务列表、表格、引用、代码块、行内代码、链接和图片。

### 9.2 LaTeX

兼容以下形式：

- 行内：`$...$`、`\\(...\\)`。
- 块级：`$$...$$`、`\\[...\\]`。

渲染失败时保留原始公式文本，不得导致整篇文档白屏。公式区域应支持横向滚动，避免在小屏幕上裁切。

### 9.3 代码块

- 保留语言标识。
- 支持常见语言的语法高亮。
- 支持横向滚动。
- 长代码不能撑破页面宽度。
- 复制代码属于阅读辅助能力，可以提供；不属于编辑能力。

### 9.4 图片

- 支持远程 URL 和同步资源 URL。
- 使用缓存、占位、失败重试和点击放大。
- 限制图片最大展示宽度，避免撑破布局。
- 图片 URL 必须经过协议和域名策略校验。

### 9.5 链接安全

只允许 `https`、`http`、`mailto` 和站内锚点等协议；拒绝 `javascript:`、`data:` 等危险协议。外部链接通过系统浏览器打开，站内锚点在阅读页内滚动。

## 10. 数据模型

### 10.1 文档

```text
Document
  id: String
  folderId: String?
  title: String
  html: String
  createdAt: DateTime
  updatedAt: DateTime
  pinned: Boolean?
  syncVersion: Integer?
```

### 10.2 卡片

```text
Card
  id: String
  type: single | multiple | truefalse | note
  folder: String
  question: String
  options: Map<String, String>
  answer: List<String>
  noteContent: String?
  explanation: String?
  tags: List<String>
  dueAt: DateTime
  createdAt: DateTime
  updatedAt: DateTime
  ease: Double?
  interval: Double?
  reviews: Integer
  order: Integer?
  mastery: String?
  correctRate: Double?
  knowledgePoint: String?
  source: String?
  suspended: Boolean
  fsrs: FsrsState?
```

### 10.3 FSRS 状态


### 10.5 账户与同步元数据

本地数据库必须带 `accountId` 或独立账户命名空间。同步元数据至少包括：

- `lastSyncAt`：服务器返回的同步时间。
- 每个对象的 `serverVersion`。
- `deviceId` 和服务器设备 ID。
- 待上传对象队列。
- 删除对象墓碑或签名记录。
- 最近一次错误、重试次数和下次重试时间。

## 11. 本地存储与离线策略

1. 使用 SQLite 保存文档、卡片、复习事件、设置、市场缓存和同步队列。
2. 卡片列表必须为常用筛选字段建立索引：`accountId`、`folder`、`type`、`dueAt`、`updatedAt`、`suspended`。
3. 文档按 `accountId + id` 唯一；卡片按 `accountId + id` 唯一。
4. 完成复习时，在一个本地事务中更新卡片、插入复习事件、更新复习统计和同步队列。
5. 网络不可用时允许阅读缓存和复习；首次登录且没有本地缓存时必须提示需要网络。
6. 市场列表可以缓存，但市场数据需要显示缓存时间；下载牌组必须在线或具备完整本地包。
7. 账户退出时删除或加密隔离该账户的本地数据，不能被下一个账户看到。

## 12. 云同步需求

### 12.1 API 对接范围

目标后端 V2 接口包括：

| 能力 | 接口 |
| --- | --- |
| 批量同步 | `POST /api/v2/sync/batch` |
| 全量或增量拉取 | `GET /api/v2/sync/full` |
| 同步历史 | `GET /api/v2/sync/history` |
| 删除同步对象 | `DELETE /api/v2/sync/:objectType/:objectId` |
| 设备同步登记 | `POST /api/v2/sync/device/:deviceId` |
| 登录账户资料 | `GET /api/v2/me/profile` |
| 牌组市场 | `/api/v2/decks` 及详情、收藏、下载相关接口 |

具体请求字段和响应结构应以当前后端路由与 OpenAPI/接口测试结果为准，客户端不得只依据页面字段拼接请求。

### 12.2 同步触发

- 登录后执行一次全量同步。
- 本地复习或设置变更后进行防抖增量推送。
- App 回到前台时检查同步。
- 网络恢复时触发同步。
- 定时同步由移动端生命周期允许的后台机制实现；不能假定 App 始终在后台运行。
- 退出登录前尽力同步，但不能阻塞退出超过明确超时时间。

### 12.3 冲突策略

- 默认服务器版本优先，等价于 `SERVER_WINS`。
- 卡片内容字段使用服务器版本；若本地复习次数不少于服务器版本，保留本地 FSRS 和复习状态，再以服务器内容字段合并。
- 文档比较 `updatedAt`，较新版本胜出。
- 设置采用字段级合并；本地复习计划和本地显示偏好不能被空服务器字段覆盖。
- 冲突结果必须记录日志，并在同步详情中可见“已自动处理”。

### 12.4 重试

- 网络超时、连接断开和 5xx 使用指数退避。
- 4xx 认证错误先刷新令牌；刷新失败后要求重新登录。
- 4xx 数据校验错误不无限重试，标记为失败并允许用户查看原因。
- 批量请求上限按 Electron 现有行为控制为每批不超过 100 个对象。

## 13. 状态与异常处理

每个主要页面至少定义以下状态：加载中、成功、空数据、网络错误、权限错误、数据损坏和离线成功。

| 场景 | 处理要求 |
| --- | --- |
| 首次加载 | 骨架屏或局部加载，不显示空数据误导用户 |
| 无文档 | 显示空知识库，不显示创建按钮 |
| 无卡片 | 显示空卡片库，并说明可从桌面端或市场获得内容 |
| 无待复习 | 显示今日已完成或当前筛选范围无到期卡片 |
| 网络断开 | 显示离线标识，继续使用本地内容 |
| 同步失败 | 保留本地操作，显示待同步数量和重试入口 |
| 令牌失效 | 尝试刷新；失败后进入登录页并保留本地数据 |
| 无权限 | 显示原因和返回入口，不显示空白页面 |
| 牌组包损坏 | 删除临时文件，提示重新下载，不写入半成品卡片 |
| 图片或公式失败 | 保留替代文本，不能影响正文阅读 |

## 14. 安全与隐私

- 访问令牌、刷新令牌、记住的密码不得写入普通 SQLite 或日志。
- 所有云端请求使用 HTTPS；开发环境允许配置测试服务器，但必须显式标识。
- 对 Markdown 链接、图片 URL、外部跳转协议做白名单校验。
- 下载包需要校验 manifest、版本、文件清单和内容格式。
- 日志中不得打印密码、完整令牌、用户隐私资料和完整卡片正文。
- 账户切换必须清理旧账户的查询缓存、同步队列和市场收藏。
- 复习事件中的题干快照仅用于历史展示，按账户隔离。

## 15. 性能与可用性指标

- 本地已有数据时，App 冷启动后 2 秒内显示可操作的复习首页骨架或缓存内容。
- 1000 张卡片的列表滚动保持流畅，不一次性构建全部复杂 Markdown Widget。
- 复习评分本地落库应在用户操作后 200 ms 内完成，网络请求不得阻塞页面。
- 文档详情支持大内容分段渲染；单篇 1 MB 内容不得导致明显卡顿或崩溃。
- 所有主要按钮支持无障碍标签、足够触控面积和系统字体放大。
- 横屏、窄屏和系统返回手势不能造成按钮遮挡或状态丢失。

## 16. 可测试性要求

- 复习队列生成、每日上限、优先级、到期判断和评分映射必须有单元测试。
- FSRS 适配器必须用固定时间和固定输入测试四档评分结果。
- Repository 必须有本地数据库、同步队列和冲突合并测试。
- Markdown 渲染必须覆盖危险链接、公式失败、代码块、图片失败和表格。
- 页面必须有登录、离线复习、市场下载失败、账户切换和同步重试的 Widget/集成测试。
- 关键页面可增加 Golden 测试，但不能用 Golden 替代行为测试。

## 17. 验收标准

### 17.1 登录和账户

- 未登录用户无法进入完整主界面。
- 正确账户可以登录并看到自己的本地/云端数据。
- 令牌刷新失败时可重新登录，旧账户本地数据不会被新账户看到。
- `SUSPENDED` 和 `BANNED` 账户显示明确原因。

### 17.2 阅读和浏览

- 文档、卡片可以搜索、筛选、排序和打开详情。
- Markdown、GFM、LaTeX、代码、图片和安全链接正常渲染。
- 所有内容页面没有编辑、删除、导入和导出入口。
- 缓存内容在断网时可以打开。

### 17.3 复习

- 到期队列排除暂停卡片并遵守每日总上限、新卡上限。
- 单选、多选、判断和速记词条都能完成一轮复习。
- 答案反馈和 FSRS 评分顺序正确。
- 每次评分只产生一个复习事件，卡片下次到期时间被更新。
- 断网时评分仍可完成，网络恢复后进入同步队列。
- 复习历史和热力图与本地事件一致。

### 17.4 市场和同步

- 市场支持搜索、排序、分页、详情和收藏。
- 合法牌组包能导入；损坏包不会产生半成品数据。
- 登录、前台恢复和网络恢复可以触发同步。
- 冲突按服务器优先、复习状态保护和设置合并规则处理。
- 同步失败可查看状态并重试。

### 17.5 范围控制

- App 不提供文档编辑器。
- App 不提供卡片增删改和牌组发布。
- App 不提供协作审核和管理员功能。
- 代码结构允许未来增加编辑，但当前页面层无编辑入口。

## 18. 实施优先级

### P0：可用闭环

认证、账户隔离、本地数据库、卡片只读浏览、基础 Markdown 阅读、复习队列、FSRS 评分、本地复习历史和基础同步。

### P1：完整学习体验

文档目录、LaTeX、代码高亮、图片缓存、统计热力图、离线队列、冲突处理、市场搜索、牌组详情和下载订阅。

### P2：体验增强

市场更新提醒、系统分享/复制代码、更多统计、平板布局、通知提醒、同步历史详情和更细的可访问性支持。

### 不纳入本阶段

App 内容编辑、牌组上传发布、协作贡献审核、WebDAV 双向能力和桌面专属功能。
