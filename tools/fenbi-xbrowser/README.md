# 粉笔错题导出器（X 浏览器用户脚本）

## 使用方法

1. 在手机 X 浏览器的用户脚本/脚本管理功能中新建脚本。
2. 将 `fenbi-wrong-answer-export.user.js` 的全部内容复制进去并保存。
3. 登录粉笔，打开错题或答题记录页面。
4. 等待页面加载后，点击右下角的“重新读取页面请求”。
5. 如果“未获取”数量大于 0，先点击“补齐所有题目”；导出按钮也会在导出前自动补齐。
6. 使用“导出错题 MD”“导出错题 JSON”或“导出错题 HTML”。

脚本只在当前页面内存中保存数据，不会把题目、Cookie 或接口参数发送到第三方服务器。粉笔返回的 `//fb.fenbike.cn/...` 图片地址会在导出时自动转换为 `https://fb.fenbike.cn/...`，HTML 和 Markdown 会保留图片，JSON 中的 `content`、`options`、`solution` 也会保存转换后的 HTML。

用户答案接口通常包含比当前页面已加载题目更多的记录。脚本会使用页面实际捕获到的题目接口参数，按用户答案中的 `key`/`id` 尝试补抓缺失题目；如果某条题目详情仍未返回，导出文件会保留这条记录并标记 `questionLoaded: false`，不会静默丢失。

导出排序提取题目来源标题中的“第 N 题”，然后跨所有试卷按 N 从小到大排序，不把卷名作为排序条件。例如吉林卷第63题会排在湖南卷第82题前面；题号相同时再按接口记录的出现顺序。JSON 的 `sequence` 是本次导出中的全局序号，`questionNumber` 是标题解析出的题号，`originalOrder` 是答案接口记录的原始遍历序号。Markdown 会使用明确的 `.md` 文件名；脚本对 X 浏览器使用 `text/plain` 和 UTF-8 BOM，避免被识别为 `.bin`。

## 数据关联规则

题目接口中的 `globalId`（例如 `3_1_f9oks`）对应用户选项接口对象的 `key`；如果没有匹配到，则使用数字 `id` 继续匹配。

- `status: -1` 或 `scoreRate: 0`：错题
- `status: 1` 或 `scoreRate: 1`：答对
- `answer.choice` 和 `correctAnswer.choice`：从 `0` 开始的选项下标，`0/1/2/3` 分别对应 A/B/C/D

## 注意事项

脚本会捕获页面实际发出的接口请求，所以不依赖固定的 `key`、`examcatid` 或其他查询参数。默认导出错题；“导出全部已捕获”会导出当前页面已经加载到的全部题目，包括答对和未匹配答案的题目。

如果首次打开页面时脚本没有捕获到请求，点击“重新读取页面请求”即可根据浏览器的资源记录重新请求接口。若页面有分页，需要逐页打开或滚动加载后再导出。
